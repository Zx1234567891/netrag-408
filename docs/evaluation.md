# 评测结果与验收口径

公开评测包含两组原创查询及来源 ID。演示组有 29 条用例，其中 26 条有排序标注；真题组有 24 条用例，其中 18 条有排序标注。真题组需要先导入本地交付包；评测文件没有转载题干、选项和解析。按题号精确查询单独验证，不参与排序指标。

```sh
python -m netrag.evaluate eval/demo.jsonl --output eval_local/demo.json
python -m netrag.evaluate eval/exam.jsonl --data-dir local_data --output eval_local/exam.json
```

以下是 Windows / Python 3.12 默认离线后端的一次实测，不包含加载语料、初始化索引、浏览器往返或外部模型调用。延迟统计覆盖整组用例的检索和本地回答。

| 语料 | 检索策略 | Precision@3 | 上下文精确率 | Hit@3 | P95 |
| --- | --- | ---: | ---: | ---: | ---: |
| 演示 | BM25 | 28.21% | 64.74% | 69.23% | 0.90 ms |
| 演示 | 向量 | 28.21% | 64.74% | 69.23% | 0.51 ms |
| 演示 | 混合 | 28.21% | 64.74% | 69.23% | 0.46 ms |
| 本地真题 + 考点 | BM25 | 64.81% | 92.13% | 100.00% | 0.71 ms |
| 本地真题 + 考点 | 向量 | 57.41% | 88.89% | 94.44% | 0.50 ms |
| 本地真题 + 考点 | 混合 | 59.26% | 91.67% | 94.44% | 0.49 ms |

演示组的 4 条数值断言、3 条资料不足断言全部通过；真题组的 4 条精确题号断言、2 条资料不足断言全部通过。额外逐题核对了 162 道计网真题的 API 精确查询，全部返回正确 ID。两组离线用例均在 5 秒内返回。它们验证了本地行为，不能推断生成模型的正确率、幻觉率或端到端时延。默认混合检索的 Precision@3 未达到 92% 的验收目标；小样本里 BM25 的表现优于默认混合策略。演示集有些问题只标注了一个或两个相关文档，以固定分母计算的 Precision@3 理论上限为 65.38%，适合回归比较，不适合作为 92% 门槛的验收集。

每个有检索标注的用例按 `前 3 名相关来源数 / 3` 计算 Precision@3。上下文精确率对命中的每个相关位置计算截至该位置的精确率，再求平均；没有相关命中记 0。Hit@3 表示前三名至少有一条已标注相关来源。当前标注数量较小，正式验收应扩充独立、盲标的查询集，并校对候选集的相关来源覆盖。

在相同的本地真题样本上，另启用 BGE 向量、FAISS 和 jieba，保留 RRF 排序、不开启交叉编码器时，混合检索得到 Precision@3 **66.67%**、上下文精确率 **94.44%**、Hit@3 **100%**，P95 为 **15.41 ms**。这次运行使用 CPU、4 个 OpenMP 线程和 10 个单路候选。

生成验收需要实际使用的模型与人工审查。运行 `python -m netrag.evaluate eval/exam.jsonl --data-dir local_data --strategy hybrid --allow-llm --output eval_local/answers.json` 后，可将人工核对的 `id`、`answer_sha256`、`correct`、`hallucinated` 写入 JSONL 并用 `--judgments` 评估。若实际输出变化，评测会拒绝复用旧标注。当前没有人工审查结果，答案准确率和幻觉率留空。

本地导入的 162 道计网真题中，144 道是选择题，其中 104 道未提供独立解析；另外 18 道是综合题，交付包将解题过程放在解析字段。两道综合题的记录缺少分值。2022–2026 年有 16 道真题被标为含图，但结构化记录未保留题图链接；应用会提示缺失。对有链接的记录，读者可从来源详情打开题图。
